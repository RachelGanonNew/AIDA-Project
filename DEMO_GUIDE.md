## 🚀 Quick Demo Steps

### 1. Start the Application
```bash
docker-compose up -d
# Wait 30 seconds for services to start
```

### 2. Access Demo
- Frontend: http://localhost:3000
- Backend API: http://localhost:8000/docs

### 3. Run Test Suite
```bash
python test_demo.py
```

### 4. Demo Features
1. **Dashboard**: Show DAO health scores and metrics
2. **Proposal Analysis**: Analyze sample proposal with AI
3. **Treasury**: Display asset allocation and recommendations
4. **Governance**: Show voting patterns and predictions
5. **Hathor Integration**: Demonstrate Nano Contracts
